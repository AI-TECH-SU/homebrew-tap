# Homebrew Tap

Official Homebrew tap for [Work](https://github.com/AI-TECH-SU/work-cli), the
local-first macOS workspace manager.

## Installation

The `work` formula will be published with the first tagged Work release. Once
available, install it with:

```console
brew install AI-TECH-SU/tap/work
```
