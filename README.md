# Homebrew Tap

Official Homebrew tap for [Focus](https://github.com/AI-TECH-SU/work-cli), the
local-first macOS workspace manager.

## Installation

The `focus` formula will be published with the first tagged Focus release. Once
available, install it with:

```console
brew install AI-TECH-SU/tap/focus
```
